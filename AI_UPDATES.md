# Обновления ИИ в Molecule Mentor

## Что сделано

### 1. Улучшена работа ИИ-движка (`utils/ai_engine.py`)

#### Улучшенные промпты для русского языка
- Строгое требование отвечать только на русском языке
- Латинские буквы разрешены ТОЛЬКО в химических формулах
- Добавлены критические правила для предотвращения фантазий
- Улучшена структура ответа: определение → формула → примеры → свойства → применение

#### Улучшенная обработка ответов
- Добавлена проверка качества ответа (`_is_answer_quality_good()`)
- Улучшена очистка от странных символов (`_fix_cyrillic_confusables()`, `_sanitize_for_ui()`)
- Добавлено исправление смешанных скриптов (например, "Срirты" → "Спирты")
- Автоматическое переписывание ответа (до 3 попыток) если содержит латиницу или ошибки
- Фоллбэк ответ "Я не знаю" если модель не может дать корректный ответ

#### Обновлена онлайн-модель
- Старая: `meta-llama/Llama-3.2-3B-Instruct`
- Новая: `meta-llama/Llama-3.1-8B-Instruct` (лучшее качество, доступна в РФ)

#### Улучшена очистка текста для UI
- Фильтрация спецсимволов Unicode
- Удаление zero-width символов
- Упрощение стрелок и математических символов для совместимости с Kivy шрифтами

### 2. Статус ИИ в интерфейсе

#### Отображение статуса (правый верхний угол)
- **ONLINE** (зелёный) — работает онлайн-модель через HuggingFace
- **OFFLINE** (синий) — работает офлайн-модель через llama.cpp
- **ИИ недоступен** (серый) — нет подключения или моделей

#### Обновление статуса
- Автоматическое обновление каждые 15 секунд
- Автоматическое переключение между онлайн/офлайн в зависимости от интернета
- Кнопка с иконкой информации показывает детальную диагностику

### 3. FAB кнопка (ИИ-помощник)

#### Функционал
- Иконка робота в правом нижнем углу
- Открывает экран ИИ-помощника
- Введите вопрос и нажмите "Отправить"
- Отображается история диалога
- Статус "Думаю..." во время генерации ответа

### 4. Дуальный режим работы ИИ

#### Онлайн-режим (при наличии интернета)
- Использует HuggingFace Inference API
- Модель: Llama-3.1-8B-Instruct
- Требуется HF токен (файл `data/secrets/hf_token.txt`)
- Более качественные ответы
- Меньше ошибок по фактам

#### Офлайн-режим (без интернета)
- Использует локальную модель llama.cpp
- Модель: Llama-3.2-3B-Instruct-Q4_K_M.gguf
- Автоматическая подготовка модели при первом запуске
- Работает полностью локально

#### Автоматическое переключение
- Проверка интернет-соединения каждые 12 секунд
- Переключение на офлайн-режим при потере интернета
- Переключение на онлайн-режим при восстановлении соединения

## Известные проблемы

### Десктоп не запускается на WSL
**Проблема:** Ошибка GLX при отсутствии X11 сервера

**Решение:**
1. Настройте X сервер (VcXsrv, WSLg и т.д.) — см. `WSL_LAUNCH_GUIDE.md`
2. Или используйте Android-версию (Buildozer)

### Небольшие опечатки в ответах
**Проблема:** Иногда встречаются опечатки ("Спиры" вместо "Спирты")

**Статус:** Приемлемо, не влияет на понимание
