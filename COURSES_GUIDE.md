# Курсы в Molecule Mentor

Документация по системе курсов и тестирования.

## Структура курсов

```
Курс
├── Раздел 1
│   ├── Тема 1.1
│   │   └── Блоки контента (текст, изображения)
│   ├── Тема 1.2
│   └── ...
├── Раздел 2
└── ...
```

### Иерархия

| Уровень | Описание | Пример |
|---------|----------|--------|
| **Курс** | Основной учебный раздел | Химия 10 класс (углублённый) |
| **Раздел** | Логический блок курса | Введение в органическую химию |
| **Тема** | Конкретный подраздел | Строение атома углерода |
| **Блок** | Контент темы | Текст, изображения, примеры |

## Навигация

1. **Главный экран** → кнопка "Курсы"
2. **Список курсов** → выбор курса
3. **Разделы курса** → выбор раздела
4. **Темы раздела** → выбор темы
5. **Теория** → карточки с материалом

## Тестирование

### Прохождение теста

- Кнопка "Пройти тест" на экране курса или раздела
- 8 вопросов с вариантами ответов
- Результат сохраняется автоматически

### Система прогресса

| Метрика | Описание |
|---------|----------|
| `best_percent` | Лучший результат (%) |
| `last_percent` | Последний результат (%) |
| `attempts_count` | Количество попыток |
| `updated_at` | Время последнего обновления |

Прогресс курса = лучший результат за все попытки.

## Содержание курса "Химия 10 класс"

### Раздел 1: Введение в органическую химию
1. Предмет органической химии
2. Строение атома углерода (sp³, sp², sp гибридизация)
3. Химическая связь (σ- и π-связи)
4. Изомерия (структурная и пространственная)
5. Классификация и номенклатура ИЮПАК

### Раздел 2: Углеводороды
1. Алканы
2. Циклоалканы
3. Алкены
4. Алкадиены (полимеризация, каучук)
5. Алкины
6. Ароматические углеводороды (бензол)

### Раздел 3: Кислородсодержащие соединения
1. Спирты (этанол)
2. Фенолы
3. Альдегиды и кетоны
4. Карбоновые кислоты
5. Сложные эфиры
6. Жиры (омыление)

### Раздел 4: Азотсодержащие соединения
1. Амины
2. Аминокислоты (пептидная связь)
3. Белки (денатурация)

### Раздел 5: Углеводы и биомолекулы
1. Моно-, ди-, полисахариды
2. Глюкоза
3. Полимеры (пластмассы, волокна)

### Раздел 6: Общая химия
1. Растворы (концентрации)
2. ОВР (баланс)
3. Химическое равновесие (Ле Шателье)
4. Скорость реакции (катализ)

## База данных

### Расположение

```
data/courses/courses.db    # SQLite база курсов
```

### Схема таблиц

```sql
-- Курсы
CREATE TABLE courses (
    id INTEGER PRIMARY KEY,
    title TEXT,
    description TEXT
);

-- Разделы
CREATE TABLE sections (
    id INTEGER PRIMARY KEY,
    course_id INTEGER,
    title TEXT,
    order_index INTEGER
);

-- Темы
CREATE TABLE topics (
    id INTEGER PRIMARY KEY,
    section_id INTEGER,
    title TEXT,
    order_index INTEGER
);

-- Блоки контента
CREATE TABLE content_blocks (
    id INTEGER PRIMARY KEY,
    topic_id INTEGER,
    content_type TEXT,  -- 'text', 'image'
    content TEXT,
    order_index INTEGER
);

-- Прогресс пользователя
CREATE TABLE user_progress (
    id INTEGER PRIMARY KEY,
    course_id INTEGER,
    best_percent REAL,
    last_percent REAL,
    attempts_count INTEGER,
    updated_at TEXT
);
```
