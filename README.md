# Molecule Mentor

Интерактивное образовательное Android-приложение для изучения химии с 3D визуализацией молекул, анимациями реакций, курсами и ИИ-помощником.

## Возможности

### Обучение
- **Курсы по химии** — структурированные учебные материалы с разделами и темами
- **Теоретический материал** — подробные объяснения с формулами и примерами
- **Тесты** — проверка знаний по разделам курса с отслеживанием прогресса
- **Викторины** — быстрые викторины по категориям (органика, неорганика, молекулы, реакции, теория)
- **Статистика** — отслеживание прогресса и достижения

### Визуализация
- **3D просмотр молекул** — интерактивная визуализация 56 молекулярных структур (вода, метан, бензол, глюкоза, кофеин, аспирин и др.)
- **Редактор молекул** — создание и редактирование собственных молекул
- **Анимации реакций** — 20 химических реакций с пошаговой визуализацией (горение, нейтрализация, электролиз и др.)
- **Редактор реакций** — создание собственных анимаций реакций

### ИИ-помощник
- **Онлайн режим** — Llama-3.1-8B через HuggingFace API с поиском фактов из Wikipedia и PubChem
- **Офлайн режим** — Llama-3.2-3B локально через llama.cpp
- **Автопереключение** — автоматический выбор режима в зависимости от интернета (реальная HTTP проверка)
- **Быстрый fallback** — при проблемах с онлайн автоматически переключается на офлайн (таймаут 20 сек)
- **Русский язык** — оптимизированные промпты и автоматический перевод английских слов на русский

### Интерфейс
- **Material Design 3** — современный адаптивный дизайн
- **Тёмная тема** — комфортная работа при любом освещении
- **Статус ИИ** — индикатор состояния (ONLINE/OFFLINE) в реальном времени

## Установка

### Требования

- Python 3.12+
- pip
- Для Android сборки: Linux/WSL, Java 17, Android SDK/NDK

### Запуск на Desktop

```bash
# Клонирование
git clone https://github.com/Ya-GromovA/Molecule_Mentor.git
cd Molecule_Mentor

# Виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/macOS
# или: venv\Scripts\activate  # Windows

# Зависимости
pip install -r requirements.txt

# Запуск
python main.py
```

### Сборка Android APK

**Lite версия** (~92 МБ, модель скачивается при первом запуске):
```bash
buildozer android debug
```

**Полная версия** (~2 ГБ, модель встроена):
```bash
cp buildozer-full.spec buildozer.spec
buildozer android debug
```

### Настройка ИИ

1. **Для онлайн режима**: создайте файл `data/secrets/hf_token.txt` с вашим [HuggingFace токеном](https://huggingface.co/settings/tokens)

2. **Для офлайн режима**: модель скачивается автоматически при первом запуске (~2 ГБ)

## Система тестирования

### Тесты по разделам курса
- Автоматически создаются для каждого раздела
- Отслеживание прогресса и лучшего результата
- Вопросы привязаны к конкретным темам

### Викторины по категориям
- **Быстрая викторина** — 10 случайных вопросов
- **Органическая химия** — углеводороды, спирты, кислоты
- **Неорганическая химия** — кислоты, основания, соли
- **Молекулы** — формулы, свойства, применение
- **Химические реакции** — типы и продукты
- **Теория и понятия** — строение атома, связи
- **Сложный тест** — 20 вопросов для подготовки к экзамену

### Статистика и достижения
- Общее количество попыток
- Лучший результат
- 12 достижений (Первые шаги, Знаток, Отличник и др.)
